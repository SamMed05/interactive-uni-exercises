How QuickSort Works

QuickSort is an efficient divide-and-conquer sorting algorithm invented by Sir Tony Hoare in 1959. It picks an element as a pivot and partitions the array such that all elements smaller than or equal to the pivot precede all larger elements.

Lomuto Partitioning:

Selects the last element \(A[r]\) as pivot. Uses single scan index \(j\) and boundary index \(i\).

\(\bullet\ A[p..i] \le x\)
\(\bullet\ A[i+1..j-1] > x\)
\(\bullet\ A[r] = x\) (Pivot)
Hoare Partitioning:

Selects first element \(A[p]\) as pivot. Scans inward from both ends with two pointers \(i\) and \(j\).

\(\bullet\ A[p..j] \le x\)
\(\bullet\ A[j+1..r] \ge x\)
\(\bullet\) Fewer average swaps than Lomuto

Time & Space Complexity

  • Average Time Complexity: \(\Theta(n \log n)\)
  • Worst-Case Time Complexity: \(\mathcal{O}(n^2)\)
  • Space Complexity (Call Stack): \(\mathcal{O}(\log n)\) average auxiliary recursion stack space
