CountingSort(A, k)
n := length(A) // cardinality of A
create C[0..k]
create B[0..n-1] // output array
for i := 0 to k do // initialize C
C[i] := 0
for j := 0 to n-1 do // count occurrences
C[A[j]] := C[A[j]] + 1
for i := 1 to k do // prefix sums
C[i] := C[i] + C[i-1]
for j := n-1 downto 0 do // fill B (stable)
B[C[A[j]] - 1] := A[j]
C[A[j]] := C[A[j]] - 1
for j := 0 to n-1 do // copy B to A
A[j] := B[j]

Why Right-to-Left?

Why loop downto 0?

Processing A from right to left ensures that duplicate elements are placed into B in descending slot order, preserving their original relative order (stability).
